## The three defects that were live

1. **`DSC_0037.png` shipped raw at 37.4 MB** — 97.5% of the page. `app/page.tsx:81` rendered it through a plain `<motion.img>`, so Next's image pipeline never ran, on a 6000×4000 source displayed at ≤320 px. Now 31.8 KB of AVIF.
2. **A 27 MB Open Graph image.** Most link-preview crawlers time out fetching it and render nothing. Now generated by `next/og` at 32.9 KB.
3. **Two project cards linked to the wrong repository.** The `href`s were shifted by one — ReCueCareer pointed at `/iPalo`, Face2Learn at `/ReCueCareer`.

Also fixed: no favicon (a 404 on every load), a keyboard trap in the skills carousel, `prefers-reduced-motion` respected in zero places, body copy at ≈4.0:1 contrast, and `package.json` declaring `next@15.5.9` while the tree ran 15.5.2 — missing that release's RSC security fix.

## What shipped

**Retrieval is the spine.** Typing on the homepage re-ranks the whole corpus with real lexical BM25, showing each result's score and which fields matched. The label says "lexical" rather than "semantic" because that is what it is. With no query it renders the entire corpus in document order — fully readable without JS, fully crawlable. The same ranking powers ⌘K, so there is one ranking in the product, not two.

**Two signature components:** the skill atlas on `/skills` (Canvas 2D over a real `<ul>` that stays the source of truth, edges drawn only where a skill actually appears in a project's résumé stack line) and the trace treatment on `/experience` (a step resolves only because you genuinely reached it; no durations are shown because none exist).

**Content is frozen and machine-checked.** `content/` holds every fact, zod-validated at build time. `npm run verify:content` proves each résumé-sourced string is a substring of the extracted résumé text — 245 checks. `npm run verify:contrast` parses the tokens straight out of `globals.css` and checks 20 pairs in both modes.
